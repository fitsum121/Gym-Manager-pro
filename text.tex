## The Mobile App (`artifacts/gym-manager`)

The core product. A fully **offline** Expo React Native app for gym owners to manage their members.

**Tech stack:** Expo SDK 54, React Native 0.81, Expo Router v6, React Query, Zod, AsyncStorage, date-fns

**Key features:**
- Auth (login/register/forgot password) — stored in AsyncStorage, no server
- Customer CRUD with photo support (camera + gallery)
- Membership types: weekly, monthly, quarterly, yearly with auto-calculated expiry
- Payment recording with automatic expiry extension
- Auto-delete members unpaid for 7+ days on app load
- Search/filter by active/expired/unpaid status
- SMS integration (pre-filled messages)

**App screens:**
- `(auth)/` — login, register, forgot password
- `(tabs)/` — members list + settings
- `customer/[id]` — member detail
- `customer/add` — add member modal
- `activate` — subscription activation screen

**Subscription/licensing system:**
- Each gym owner gets a unique 6-char `gymId`
- Activation codes follow the format `GYM-{GYMID}-{YYMMDD}-{SIG8}`
- Signature uses a custom double-FNV hash with a shared secret
- Subscriptions stored locally in AsyncStorage per `gymId`

## The API Server (`artifacts/api-server`)

Express 5 server, currently minimal — its main purpose is the **license admin panel**.

**Routes:**
- `GET /api/healthz` — health check (validated via Zod)
- `GET /api/admin` — HTML license generator UI (Basic Auth protected)
- `POST /api/admin/generate-code` — generates activation codes for gym owners

**Notable concern:** Admin credentials (`fitsumgebramariam53@gmail.com` / `F1i2t3s4u5m6@`) are hardcoded in `admin.ts`. This is a security risk — these should be environment variables.
